Perché NonLinearSection?

Il motore di sezione di StrutturaNL, con gli algoritmi ricondotti al programma madre e una suite di convalida dedicata.

🧬

Legami Non Lineari

Parabola-rettangolo EC2/DIN 1045 (medi e progetto), acciaio elastoplastico con incrudimento, leggi lineari elastiche per il confronto.

🪨

Multi-Materiale & Getti

Ogni getto ha geometria e legge propria, con predeformazioni (Vordehnung). Trefoli di precompressione e barre con legge indipendente.

🌀

Fessurazione & Viscosità

Riduzione del ramo teso del calcestruzzo (tension stiffening, Mitwirkung) e viscosità semplificata con φ per il comportamento a lungo termine.

📈

Curva M-χ & Dutilità

Momento-curvatura a sforzo normale assegnato: fessurazione, snervamento, ramo ultimo e curvatura ultima per la valutazione della duttilità.

🧊

Domini N-M e N-Mx-My

Interazione uniassiale allo SLU con diagramma limite EC2 e superficie biassiale per pressoflessione deviata. Verifica del punto con Grenzdehnungen.

🛡️

Validato su INCA2

Algoritmi decodificati dal programma di riferimento e suite di convalida dedicata (test INCA2, Stab2D-NL, Dalben). UI Streamlit e grafici matplotlib/plotly.

Installazione

Una libreria Python pura con UI Streamlit opzionale — o la sezione dentro il tuo telaio non lineare.

bash 
# Clona SectionTool
git clone https://github.com/DomenicoGaudioso/SectionTool.git
cd SectionTool

# Dipendenze: numpy, scipy + UI (streamlit, pandas, plotly)
pip install numpy scipy streamlit pandas plotly

# Avvia l'interfaccia sezioni (StrutturaNL — Querschnitte)
python -m streamlit run strutturanl/ui/app.py

# Oppure usa il motore in Python
python -c "from strutturanl.analisi import AnalisiSezione; print('ok')"

# Test di convalida (INCA2 · Stab2D-NL · Dalben)
python -m pytest tests

ℹ️ L'app carica subito l'esempio del manuale (rettangolo 400×600 con 4Ø28) e importa le sezioni .inc di INCA2. Documentazione e sorgenti su GitHub.

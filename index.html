Perché CompositeSectionCheck?

Uno strumento tecnico per ingegneri strutturali che lavorano con travi composte secondo NTC2018 ed Eurocodice 4.

📐

Sezione Trasformata

Omogeneizzazione automatica calcestruzzo-acciaio con coefficiente n = E_s/E_c,eff. Calcolo preciso di baricentro e inerzia.

📊

Diagrammi di Tensione

Visualizzazione grafica della distribuzione lineare σ(y) = M·(y-y_NA)/I_tr per acciaio e calcestruzzo separatamente.

🔄

Fasi Costruttive

Confronto immediato tra fase pre-composito (solo acciaio) e post-composito (sezione omogeneizzata con soletta).

⚡

CLI Automation

Esegui analisi batch, genera report e integra nel tuo workflow di progettazione strutturale automatizzata.

📚

Riferimenti Normativi

Allineamento a NTC2018 e EN 1994-1-1 (Eurocodice 4) per la verifica di travi composte acciaio-calcestruzzo.

🔓

Open Source

Codice trasparente su GitHub. Studia gli algoritmi, modifica e contribuisci al miglioramento dello strumento.

compositecheck — CLI examples 
# Installa CompositeSectionCheck
pip install composite-section-check

# Analizza una sezione composita
compositecheck solve --profile HEA400 --slab 250 --width 3000 --moment 1200

# Esporta i risultati
compositecheck export --format json --output results/

# Genera il plot delle tensioni
compositecheck plot --phase post --output stress_diagram.png
